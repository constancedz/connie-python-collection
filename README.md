# Connie's Python Code Collection

A collection of beginner-friendly Python functions by Connie. Run the tests using Python 3:

```sh
python -m unittest -v
```

Try the sample demonstrations:

```sh
python examples.py
```

The collection includes an even/odd checker, a string reverser, a maximum finder, a vowel counter, FizzBuzz, a palindrome checker, a factorial calculator, duplicate removal, two-sum, an average calculator and a matric marks exercise.

**Important:** The matric marks function is only a coding exercise. A single mark cannot determine an official South African matric pass or qualification. Do not use it for real educational decisions.

Notes: `fizz_buzz` is intended for positive integers and does not explicitly validate that input. `remove_duplicates` requires hashable items, such as numbers or strings. The palindrome checker removes characters outside the ASCII letters and digits.
